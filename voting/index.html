OBS setup — recommended settings
  • Source type: Browser
  • URL: paste either URL above
  • Use the size noted next to each overlay (the widget centers within those bounds)
  • Check "Refresh browser when scene becomes active" so the overlay always shows the current poll state when you switch scenes
  • Position: bottom-left or lower-third for the poll widget; bottom-right for the ticker is a common pairing
  • Both overlays only render during active polls — safe to leave in every scene

Anti-bot guards

All per-vote limits below are scoped to a single poll. A new poll starts every counter fresh — voting in one poll never blocks anyone from voting in the next, even from the same Kick account or IP.

  • Require Kick login (no anonymous votes)
  • Reject accounts < 24h old
  • Require verified email
  • 1 vote per Kick username (this poll only)
  • 1 vote per IP (this poll only · proxy ranges blacklisted)
  • Require following the channel (toggle, this poll only)
  • Require N minutes of watch time (toggle)
  • Cross-poll voter-pattern detection (background job, all polls)

Heuristics run server-side per vote and stamp the verified / new acct / suspect flags shown in the "Who voted" tail. Suspect votes are still recorded but excluded from the live tally unless a mod manually approves.
